## 1. Introduction
This repository demonstrates three introductory Artificial Intelligence projects. Each project focuses on a different concept: rule-based conversation, adversarial search in a game, and content-based recommendations.

## 2. Task 1 — Chatbot with Rule-Based Responses
**Objective:** Respond to user messages using predefined rules.

**Implementation:** The chatbot converts input to lowercase and checks for keywords using conditional statements. A loop allows the conversation to continue until the user enters an exit phrase.

**AI concept:** Basic natural language processing and conversation flow.

**Expected result:** The chatbot responds to supported greetings and questions about Python, AI and Machine Learning.

## 3. Task 2 — Tic-Tac-Toe AI
**Objective:** Play Tic-Tac-Toe against a computer opponent.

**Implementation:** The program represents the board as nine cells. The Minimax algorithm explores possible moves. The AI selects the move with the highest score while assuming the human opponent chooses moves that minimize that score.

**AI concept:** Game theory, state-space search and Minimax decision-making.

**Expected result:** The AI plays optimally and should not lose when the algorithm is functioning correctly.

## 4. Task 4 — Recommendation System
**Objective:** Recommend movies based on user preferences.

**Implementation:** Each movie has a set of genres. The program compares those genres with the user's selected genres and ranks matching movies by overlap.

**AI concept:** Content-based filtering.

**Expected result:** Movies with more matching genres appear higher in the recommendation list.

## 5. Tools and Technologies
- Programming language: Python
- Concepts: conditional logic, loops, functions, search algorithms, set operations and ranking
- External libraries: None

## 6. Conclusion
The three projects provide practical introductory experience with rule-based systems, decision-making algorithms and recommendation techniques. They can be extended with graphical interfaces, larger datasets and more advanced models.
